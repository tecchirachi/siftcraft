# ShiftCraft

バイトのシフトと給料を、**深夜割増・残業割増・交通費まで含めて正確に計算する** Webアプリです。
外部APIは一切使わず、データはブラウザの localStorage にだけ保存されます（運用コスト 0円）。

## なぜ作ったか

塾講師のバイトで、給料明細を見るまで「今月いくら入るか」が分からず、深夜帯にかかるシフトや残業の割増が合っているか自分で検算するのが大変でした。
シフトを入れるだけで見込み給料が分かり、割増の内訳まで確認できるツールが欲しくて作りました。

## 主な機能（MVP）

- 時給・交通費の設定
- シフトの追加・削除（日付 / 開始・終了 / 休憩）
- 給料の自動計算: 実働時間、残業割増（8時間超 +25%）、深夜割増（22:00–翌5:00 +25%、残業と深夜の重なりは +50%）
- 日をまたぐシフト（例: 22:00–翌2:00）に対応
- 合計時間・合計金額の表示（月別フィルタ対応）
- 目標金額の進捗表示、CSVエクスポート、入力バリデーション
- データは localStorage に保存（サーバーなし）

## 使用技術

- React + TypeScript（Vite）
- Vitest（給料計算ロジックの単体テスト）
- GitHub Pages で公開予定（静的ホスティング、無料）

選定理由: 開発バイトで最もよく使われる React/TypeScript を、型で給料計算の入力・内訳を表現できる形で使うため。計算ロジックは UI から分離し、テストで正確さを担保しています。

## 起動方法

```bash
npm install
npm run dev     # 開発サーバー
npm test        # 給料計算のテスト
npm run build   # 本番ビルド
```

## 工夫した点

- 給料計算を `src/lib/pay.ts` に純粋関数として切り出し、通常 / 残業 / 深夜 / 日またぎ / 残業×深夜の重なり の6ケースをテストで検証
- 休憩・割増のルールをコード冒頭に明記し、勤務先ごとの規定差は「設定で変更できる目安計算」と割り切った
- 外部API・サーバーを使わない設計で、個人情報（シフト・給料）が端末の外に出ない
